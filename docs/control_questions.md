# Контрольные вопросы (черновик)

Вопросы, на которых поиск или ответ раньше ошибались. После каждого изменения правил поиска
они проверяются, чтобы старые исправления не сломались.

Два уровня проверки:
- **Поиск** (без модели, секунды): абзацы из столбца «Должны найтись» обязаны попасть в материал для модели.
- **Ответ** (с моделью, минуты): в ответе есть ключевые факты и ссылки на эти абзацы.
