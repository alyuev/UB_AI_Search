# Упаковка и проверка на Windows (этапы 15–16)

Сборка: `.venv\Scripts\python scripts\build_dist.py --mode user|builder|both` (≈ 30–45 с на режим, из них zip — основное время).
Результат: `dist\<режим>\BilingualTextAnalyzer\` (папка, внутри `start.bat`) и `dist\BilingualTextAnalyzer-<режим>.zip` (внутри верхняя папка `BilingualTextAnalyzer\`), размеры — в `dist\sizes_<режим>.json`.
Размеры ниже в десятичных МБ (1 МБ = 10^6 байт; Проводник Windows показывает чуть меньшие «МБ» = МиБ).

**Запасной вариант без Vulkan.** Если на компьютере нет Vulkan-видеокарты/драйвера, смысловая часть поиска отключается (останется полнотекстовый поиск и всё остальное), пока рядом не положат ONNX-модель. Включать ONNX bge-m3 (560 МБ) в дистрибутив нецелесообразно (+≈ 470 МБ в zip), поэтому он опущен и описан в README (раздел «Если что-то не так»). Для этого достаточно положить `model.onnx` в `models\bge-m3\` и выбрать «onnx-cpu» в Настройки → Embeddings (индекс вектора записан моделью bge-m3 — ONNX совместим с ним по контролю качества косинус ≥ 0,98).

## Заметки по реализации

- На этой машине выставлена переменная `NoDefaultCurrentDirectoryInExePath`: `cmd /c start.bat` из консоли без пути не находит файл в текущей папке. Двойной щелчок в Проводнике и запуск по полному пути работают; в тестах использовались полные пути.
- Исправления, найденные при упаковке: путь исходного файла для сборки теперь считается от папки программы, а не от текущего каталога процесса; список источников скрывает `README.md`; ID книги проверяется (латиница/цифры/`_`/`-`/`.`); после отмены или сбоя сборки открытая база переоткрывается (раньше приложение оставалось без базы); красная полоса при недоступной базе; выбор книги в шапке.
- **Секреты не упаковываются.** `data/secrets.json` (ключи API облачных провайдеров), `data/settings.json`, `data/history.db` и `.env` в дистрибутив не копируются; кроме того, `build_dist.py` перед архивированием проверяет собранную папку (`find_secret_files`) и прерывает сборку, если находит такие файлы (покрыто тестом).
- Сборка воспроизводима из репозитория (`scripts/build_dist.py`); embeddable-zip кэшируется в `dist\_cache` (скачан один раз с python.org).
