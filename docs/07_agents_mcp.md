# Подключение ИИ-агентов (Hermes, Claude и др.)

К SmartSearch может подключиться ИИ-агент. Агент передаёт вопрос, программа ищет по книге и отвечает. В ответе уже есть **готовое оформленное сообщение** (Markdown, до ~3800 знаков — укладывается в одно сообщение Telegram). Агент пересылает его пользователю без изменений.

Способов подключения два, инструменты у них одинаковые:

| Способ | Адрес | Для кого |
|---|---|---|
| **MCP** (рекомендуется) | `http://127.0.0.1:8765/mcp` | Hermes, Claude Code/Desktop, Cursor и другие агенты, которые понимают MCP |
| **REST** | `http://127.0.0.1:8765/api/agent/...` | свои скрипты, n8n, боты без MCP |

Порт может отличаться: смотрите адрес в чёрном окне программы.

## Что умеет агент

| Инструмент MCP | REST | Что делает | Время |
|---|---|---|---|
| `ask_book` | `POST /api/agent/ask` `{"question": "..."}` | Ответ на вопрос по книге со ссылками на абзацы и списком источников | 10 с – несколько минут (зависит от модели) |
| `search_book` | `GET /api/agent/search?q=...&k=5&mode=hybrid` | Найти абзацы, без ответа модели | ~1 с |
| `get_paragraph` | — | Полный текст абзаца `147:2.4` (RU + EN), можно с соседними | мгновенно |
| `get_answer` | `GET /api/agent/answer/{job_id}` | Забрать ответ, если `ask_book` не дождался его за 4 минуты | — |

Вопрос от агента выполняется так же, как вопрос со страницы. Он использует те же модель, промты и настройки, появляется в ходе работы и попадает в **Историю**.

Пример готового текста:

```
❓ *Кто такие Мелхиседеки?*

Мелхиседеки — сыны-учителя… [35:0.1]

📚 *Источники*
• `35:0.1` — _Документ 35. Сыны Бога Местной Вселенной · …_
  «…»
```

## Hermes на этом же компьютере

Это самый простой вариант: SmartSearch и Hermes работают на одном Windows-компьютере.

1. Запустите SmartSearch как обычно (`start.bat`).
2. В файл `~/.hermes/config.yaml` добавьте:

   ```yaml
   mcp_servers:
     smartsearch:
       url: "http://127.0.0.1:8765/mcp"
       timeout: 300          # вопрос к модели может идти несколько минут
       connect_timeout: 15
   ```
3. В Hermes выполните `/reload-mcp` или начните новую сессию.
4. Напишите боту в Telegram, например: «Спроси у книги: что такое Настроитель Мысли?». Hermes вызовет `ask_book` и пришлёт ответ в чат.

Ключ для этого не нужен: с самого компьютера (127.0.0.1) доступ открыт.

Hermes сам решает, когда вызывать инструмент. Чтобы он всегда пересылал ответ как есть, можно добавить в его личность или инструкции строку: *«На вопросы о Книге Урантии вызывай инструмент ask_book и отправляй пользователю поле text без изменений»*. В описании инструментов это уже сказано.

## Hermes на другом компьютере, в WSL или Docker

Это случай, когда Hermes работает не там, где SmartSearch: в WSL, в Docker, на другом ПК в сети или на сервере.

1. Придумайте длинный ключ, например сгенерируйте его командой `python -c "import secrets;print(secrets.token_urlsafe(32))"`.
2. Запустите SmartSearch так, чтобы он принимал подключения по сети. Например, создайте рядом с `start.bat` файл `start-agents.bat`:

   ```bat
   @echo off
   set SMARTSEARCH_AGENT_TOKEN=ваш-ключ
   set SMARTSEARCH_HOST=0.0.0.0
   call start.bat
   ```
   Ключ можно вместо этого записать в `data/settings.json` как `"agent_token": "ваш-ключ"`. Без ключа программа не согласится слушать сеть.
3. Разрешите порт 8765 в брандмауэре Windows (Windows спросит об этом при первом запуске, отметьте «Частные сети»).
4. В `~/.hermes/config.yaml`:

   ```yaml
   mcp_servers:
     smartsearch:
       url: "http://<IP-адрес-Windows>:8765/mcp"   # из WSL: адрес из `ip route | grep default`
       headers:
         Authorization: "Bearer ваш-ключ"
       timeout: 300
   ```

**Что видно снаружи.** С других компьютеров доступны **только** `/mcp` и `/api/agent/*`, и только с ключом. Страница программы, настройки, ключи облачных моделей и сборка базы остаются доступны только с этого компьютера.

**Hermes на облачном сервере (VPS).** Сервер не может сам зайти на домашний компьютер. Нужен туннель, например Tailscale (проще всего: оба устройства в одной частной сети, адрес вида `100.x.x.x`) или `cloudflared tunnel`. Ключ обязателен. Не открывайте порт в интернет напрямую через роутер.

## Проверка без агента

```bash
curl -s "http://127.0.0.1:8765/api/agent/search?q=Настроитель%20Мысли&k=3"
```

```bash
curl -s -X POST http://127.0.0.1:8765/api/agent/ask -H "Content-Type: application/json" -d "{\"question\": \"Что такое Настроитель Мысли?\"}"
```

С ключом добавьте `-H "Authorization: Bearer ваш-ключ"`.

## Если что-то не так

- **Ответ «⏳ Ответ ещё готовится»** означает, что модель отвечает дольше 4 минут. Агент сам вызовет `get_answer`, или попросите его об этом. Можно ускорить: выбрать модель быстрее или уменьшить «сколько абзацев передавать».
- **401** — неверный ключ. **403** — подключение не с этого компьютера, а ключ не задан, или запрошен адрес, закрытый для сети.
- **«LM Studio недоступен»** — `search_book` работает и без модели, а `ask_book` требует запущенной LM Studio (или другого провайдера из настроек).
- **Hermes не видит инструменты** — выполните `/reload-mcp` и проверьте, что программа запущена и адрес/порт совпадают с окном программы.
